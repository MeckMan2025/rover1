== 3. Motor board, read-only (03-motor-board.txt) ==

- reg 0x14 motor type = 0 (NOT 3); reg 0x15 encoder polarity = 0; battery
  13394 mV. [smbus2 single-transaction reads at 0x34]
- Nothing in app/ ever writes 0x14/0x15; the current FastAPI stack handles
  wheel polarity in software (app/motors.py _DEFAULT_POLARITY (-1,+1,+1,-1))
  and does not use the board's closed-loop profile. If the plan wants
  encoder-servoed speeds, the board must first be configured each power-on.
- Encoders at 0x3C (<iiii): (187673, -204615, -167592, 149180), identical 5 s
  apart with the rover still. Counts are nonzero from earlier driving and the
  sign pattern matches the known FL/RR reversed wiring.
